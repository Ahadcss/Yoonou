Une personne qui a oublié son mot de passe t'écrit sur WhatsApp. Vérifie que le message vient bien du même numéro que son compte, puis génère un code et envoie-le lui. Le code est valable 24 h et ne sert qu'une fois.

⚠️ Ne génère un code que si le message WhatsApp vient bien du numéro affiché ci-dessous. Le code n'est affiché qu'une seule fois : si tu quittes la page, génère-en un nouveau.
